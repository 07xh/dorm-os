# DORM NFC V1.14 · 用用户确认的交互原型 V2 对齐原生 App

设计依据：用户提供的 `dorm_os_nfc_interactive_v2.html` 及同一原型的手机截图（首页深蓝 NFC 主卡、「设备状态」「常用场景」、底部「首页／场景／工具」）。不使用之前 V1.13 自行设计的蓝色 KPI 工作台。

## 原生页面对应

- 首页：早/午/晚动态问候 + DORM OS · NFC 助手，右侧设置入口；深蓝 NFC hero「轻触标签，立即执行」，点「扫描 NFC 标签」使用真实 Android NFC 只读 ReaderMode；设备状态读取 Android NFC 开关和现有 Root 模块响应；常用场景从当前 KernelSU `--script-bindings` 与 `--script-list` 联合生成，空状态真实展示。
- 场景：展示**当前已绑定 NFC 标签**，可点进查看标签 UUID 与解除绑定。触发开关仍调用原有 `--enable`。新增场景时选择现有 SH，由已有写入→回读→Root 绑定协议完成；如无 SH，转到编辑器先创建。
- 工具：普通 NDEF 读写工具、原有 SH 文件夹及脚本创建/导入/运行/编辑/改名/移动/删除功能；保持所有已有确认、异常处理和权限门禁。
- 底部导航严格为三项「首页 / 场景 / 工具」；系统设置通过页首按钮打开，不额外占第四个底栏入口。
- 附带 `NfcPrototypeV2Ui.kt` 专门复用高保真视觉元素。主 UI 使用暖白近灰画布、藏蓝 hero、白色状态列表、原型间距与圆角。

## 原型与实际 App 的明确区别

- 原型中「模拟扫描标签」换成真实 NFC ReaderMode；**不提供可误认真实执行的模拟成功反馈**。
- 原型硬编码的「回到宿舍」「学习模式」等场景只是示例，正式 App 仅展示真实已绑定 SH，不制造假的场景或执行记录。
- 原型中的「侧键 / 三段式」不移植（明确不在项目范围内）。
- 任何场景不硬编码校园网认证：后续自动化均以个人审核的 SH 扩展。
- 无 NFC 标签仍可检查版式、状态、原生工具及 SH 编辑；真实读写、Root 与待机行为须一加 Ace 6 验收。
