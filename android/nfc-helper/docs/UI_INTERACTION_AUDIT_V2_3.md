# DORM NFC · 交互原型 V2-3 逐页审计（真机验收版）

唯一基准：`docs/prototypes/dorm_os_nfc_interactive_v2_3.html`，辅以用户在一加手机提供的工具页、新建 SH 弹层及 NFC 扫描截图。不得以 V1.13 自拟的 KPI 工作台替代原型。

## 一、首页

- [x] 底部主导航仅有首页 / 场景 / 工具；不增设功能重复的单独主页面
- [x] 深蓝 NFC Hero + 设备状态 + 真实场景列表
- [x] 点击首页 NFC 按钮**不启动 TagInspectorActivity**，而是在 ManagerActivity 之上呈现 NfcInlineScanSheet
- [x] 读取会话仅在浮层可见且 Activity 前台时启用 ReaderMode；关闭/切后台立即停止
- [x] 扫描结果在同一浮层内呈现，含类型、记录、容量、可写及异常状态
- [ ] 真机验证 NFC 被读到后 Android 16 前台调度不会误启动独立接收页
- [ ] 手势导航、系统字号放大、输入法状态下标题/主卡不遮挡

## 二、场景

- [x] 只显示真实 KernelSU 绑定，不默认伪造回宿舍或学习模式
- [x] 全部 / 已启用 / 已停用筛选
- [x] 场景详情、编辑、停用、解绑使用主页面上的底部弹层
- [x] 原生 KSU 处理每个场景启停，停用时 Root 端拒绝自动执行
- [ ] 真机写卡→回读→绑定及碰卡执行的完整因果验收（实体标签未收到）
- [ ] 统一复用写卡会话的弹层与现有 MainActivity 一次性写入桥（**尚未完成**；不冒充已完成）

## 三、工具

- [x] 列表搜索独占一行，避免短屏横向溢出

- [ ] 真实手机检查系统状态栏、底部手势条、长列表边缘及选择控件触控面积

## 四、新建脚本

- [x] 点击「新建」先打开轻量创建弹层（名称/模板），**不立即显示整页空白代码框**
- [x] 点击「继续编辑」才进入真实 Shell 代码编辑器；只有保存时才写入 KSU 模块
- [x] 保留原有代码大小、SH 命名与语法检查
- [ ] Android 输入法弹起时复核编辑器保存按钮和光标定位（真机）
- [ ] 编辑器语法高亮、复制/粘贴行为与撤销/返回交互进一步优化（非首轮门禁）

## 五、NFC 读取浮层

- [x] 当前页面半屏容器，无独立 Activity 跳转；同层等待/读取中/成功/失败状态
- [x] 前台读取仅作只读解析，不访问 Root 或直接运行已绑定脚本
- [x] 读卡后只读报告共用 NfcTagReader；已有 TagInspectorActivity 保留作兼容入口但不再用于首页/工具入口
- [x] 关闭与暂停时取消扫描
- [ ] 真机重复贴卡、NFC 关闭后恢复、手机旋转和系统中断的生命周期验证
