# DORM OS V4.1 · 网站优先的 UI 重构

本 PR 只修改网站信息架构、首页密度与 NFC 网页交互。**不修改** KernelSU 模块、Android APK、网络认证脚本与 PR #12。

## 改动
- 桌面侧栏与手机底栏统一五入口：首页 / 学习 / NFC / 生活 / 我的。
- 新增学习中心 `/#study`：今天课程、待完成任务、原课表/任务/校园页的管理入口。
- `/#timetable`、`/#tasks`、`/#campus` 等原有深链接全部保留；侧栏高亮归属到学习；设备和设置归属我的；场景归属首页。
- NFC 扫描区域移动到最前，标签添加在列表标题区，每条标签只保留写入与编辑为主要操作，复制、网页链接测试与删除收进“更多”。
- 首页顶部卡片压缩高度；不移除已有本地课表、任务、NFC 标签、备份和计时状态。
- NFC 网页成功不等于设备动作成功；不伪造 Root 连接或系统权限。

## 验收
- `npm run check`、`npm run test:e2e` 包括五入口和历史深链测试。
- Desktop + mobile Chromium；移动端不横向溢出，NFC 编辑、读卡、写卡、中止与重新绑定功能保持。
- 复核手机浏览器 NFC 真机行为；该 PR 不等同 Android 硬件验证。
- CI 通过后再审查合并；不得因为有 KSU PR 就提前上线未验收网页。
