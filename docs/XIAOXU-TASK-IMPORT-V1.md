# 校序第一批：只读任务快照导入（2026-11-02）

本批目标是建设 **可信数据入口**，不是宣称已经连接学习通、青果或二课服务器。沿用 DORM OS V4.5.1 的主页、任务、日历、NFC、加密备份与旧版 `dorm-os-state-v1` 数据结构。

## 使用步骤
1. 在「任务」点击 **导入任务 JSON**，选择符合 `xiaoxu-task-batch-v1` 的文件（最大 1 MB），本地解析。
2. 显示本次 **新增 / 更新 / 不变** 数量及部分变化任务；**确认后**才保存至原个人任务列表。
3. 文件不包含的旧任务原样保留；文件错误、重复外部 ID、容量超过 300 时拒绝导入；不在后台访问任何第三方服务器。
4. 「校园助手」提供华水第二课堂 `https://dekt.ncwu.edu.cn/` 官方入口，目前只有跳转，没有自动读取积分。

## 标准 JSON（示例数据，非真实账号结果）

```json
{
  "format": "xiaoxu-task-batch-v1",
  "source": "chaoxing",
  "tasks": [
    {
      "externalId": "course123/work456",
      "title": "高等数学例题练习",
      "course": "高等数学",
      "due": "2026-11-20",
      "status": "todo"
    },
    {
      "externalId": "course123/work457",
      "title": "阶段练习",
      "course": "高等数学",
      "due": "",
      "status": "submitted"
    }
  ]
}
```

- `source` 必须为 `chaoxing`（学习通）、`ncwu`（华水教务）、`second_class`（华水二课）之一。
- `externalId` 由**被授权的本人数据导出器**生成，同一平台与课程任务必须稳定；**与学生学号无关**，不在文件中嵌入账号/密码/Cookie/Session。
- `status` 只接受 `todo` / `submitted` / `graded` / `returned` / `unknown`，并且和本地 `done` 勾选分开。
- `due` 使用真实存在的 `YYYY-MM-DD` 日期，或空字符串；未确认的精确截止时刻不要猜。未来需增加可选的带时区时间。
- 此为**校序内部中间格式**，不能把任意 `xuexitong-cli --json` 原始输出直接改名导入。需要校验实际 CLI 输出字段后另外实现转换适配器。

## 数据语义与风险控制
- 去重键是 `source + externalId`；旧版手动任务不与导入任务混淆。首次导入生成本地 ID，以后更新同一条。
- 更新官方标题、日期、课程和状态，但保留个人 `done` 勾选与自定义分类；缺失不代表完成/撤销。
- 保存失败回滚本轮内存修改；无效文件在规划阶段失败，不影响已有任务。
- 原本存储及普通/加密 V1 备份照旧兼容，新增的 `source/sourceId/sourceStatus/course/importedAt` 会在旧备份修复函数 `safeState` 白名单校验后保留。
- 文件内容只在本浏览器解析、确认后存入本地存储，**网页不会收集学校登录凭据，也不会根据此文件自动提交作业、签到或刷新学校状态**。
- 这是第一批最小切片。青果 KINGO、SleepDown/拾光青果、学习通查询、二课官方数据接口的后续真正只读连接按 Issue #30 独立验收；**当前未开通后台实时更新**。

## 验收
- `npm run check`：语法、离线脚本、原任务/备份/NFC 回归，以及任务快照严格验证/幂等/状态隔离。
- `npm run test:e2e`：桌面与手机仿真浏览器测试本地导入、状态变更、重复导入、恶意/重复文件拒绝、二课入口。
- 第三方学校登录与 Android 真机 NFC 需要单独完成，不在本批伪装成功。
