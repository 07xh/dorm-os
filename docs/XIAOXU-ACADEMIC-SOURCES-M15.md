# 校序 M15｜学习通与第二课堂现有连接器完善（2026-11-03）

## 已完成 / 绝不冒充真实绑定
- 继续使用原本 `/login/`、`我的 → 数据连接`、现有 D1 `academic_connections`、`academic_assignments`、`academic_verified_batches` 和 `academic_verified_records`。
- **学习通**：复用 `lib/academic-connector-runner.mjs` 与 `lib/academic-readonly-sync.mjs`，没有额外建立登录页、凭证表或定时抓取任务。连接器仅接受受信任后端适配器的真实校序 owner 绑定证明（`principalBoundTo`），要求数据源属于华水本人。
- **学习通多页任务**：先校验全部页面的来源、完整性、记录 ID 和跨页重复，再将受限记录作为**一个 D1 事务**写入；后续页失败、空结果未证实、超过限制均不写入任何新作业，保留原数据。对普通手动导入依旧限制单次 20 项，不扩大前端输入限额。未核实截止日期保持未知。
- **第二课堂**：复用既有基于本人 HAR 的只读记录与官方合计数据适配器。写入前必须证明学校账号对应校序本人；活动查询与积分查询之间也检查账号保持一致。已核算积分与志愿服务时长不能混算。
- **一个连接中心**：三个平台使用原有卡片内的折叠指引；“打开官网”不是账号绑定，个人 JSON 导入不是自动同步。

## 验收范围
- 学习通：多页成功只生成一次同步事务、身份不一致阻止写入、后续页查询失败零部分写入、手动导入限制不回退。
- 第二课堂：学校身份错配与查询中途切换拒绝、官方分数与活动明细事务共存、历史数据不覆盖。
- 手机与电脑：原连接中心三张卡片可读、无默认私人 API、无需新用户账户、正式网站不要求学校账号密码。

## 真实平台未完成事项
目前仍**没有**经过学校授权、可撤销且能实际续期的校序第三方登录凭证。学习通的 `xuexitong-cli` 本机只读导出只能生成部分覆盖导入文件；第二课堂先前 HAR 证明字段与 API，并不意味着校序能复用历史 Cookie。项目不提交学校密码、Cookie、学号或 HAR 原文。没有获验证据时绝不启用前台“已绑定”“自动同步”等状态。

下一步需要校方或本人受控组件提供经过许可的 `verifySession/readPage/readPost` 实现并与本人真实数据核验，才能开启正式只读自动同步；不得绕过认证或限制。
