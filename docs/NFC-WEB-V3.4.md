## 证据边界
网页链接测试不能证明读卡。前台 Web NFC 的写入/读取事件也不能证明手机系统动作已执行。Web NFC 需要兼容浏览器、HTTPS、前台授权与实体标签；一加 Android 16 实机仍待验证。
