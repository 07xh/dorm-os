# DORM OS V4.2 网站 UI：课表和生活管理

基于 PR #24 继续改进网站，不修改 APK、KSU、NCWU 脚本或用户本地存储模型。

- 课表加入单日/整周视图，单日按周一至周日切换；手机默认单日，桌面默认整周。
- 课程卡片显示名称、时间、教室；旧编辑/删除功能保留，删除收在更多菜单。
- 历史 .ics 日期课程保留独立分区，不与按星期循环的课程混淆。
- 生活页面改用提醒/物品分段界面；按当前分段显示唯一的新增动作。
- 删掉与学习中心重复的生活页跳转卡；删除提醒和物品均需人工确认。
- 保留旧的 localStorage schema，旧任务/提醒/物品/标签可直接读取。
- 新增桌面与移动端 E2E 验收，必须 CI 通过，真机仍需单独验证。
