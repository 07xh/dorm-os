# 校序 V9.1：真实信息优先，减少重复和焦点跳失

基于 Taste Skill 对工作台结构的约束，以及 Impeccable 的应用界面、触控、无障碍与动效规范，沿用 V9 现有视觉与数据模型，不引入新组件库或新的连接器。

- 首页 Hero 改成选中日期的精简安排概览，保留日期筛选、课程数和到期任务数，只显示一条课程速览，避免和下方「今日课表」重复渲染。
- 校区名称从真实偏好动态读取；切换今天/明天/后天时标题一致更新。
- 首页移除静态写死「青果未连接」的连接状态卡，避免与现有「我的 → 数据连接」中心出现冲突。来源数据的唯一权威状态仍由数据连接中心展示。
- 没有本地课程时，今日课表卡直接提供已有的「添加课程」功能。
- 全量 DOM 重绘时，在常用日期筛选、课表日/周、任务筛选和任务勾选上恢复相同控件焦点，减少键盘/辅助技术操作中断。
- 更新 PWA 缓存版本以避免加载旧首页。保留原有通知、课表、任务、设置、云端登录和业务 API。

## 验收

- GitHub Actions 内运行 `npm run check` 和桌面/手机 Playwright；
- 首页没有静态状态卡、没有重复的课程列表和「下一节」浮卡；
- 日期切换后标题与校区偏好一致，空课表按钮打开真实现有新增课程弹窗；
- 使用键盘切换日期、筛选时焦点不消失；
- 手机固定导航与登录弹窗、离线缓存、官方通知和私有端点保护保持不变。
