# DORM OS V3.3 · 个人版实施记录

## 本次改动

- 视觉：默认蓝白主题 + 极轻玻璃效果，保留用户可选择的深色主题。
- 首页：快捷场景、当日课表、待办、生活提醒、个人设备均衡呈现，减少虚构状态和重复统计。
- 移动端：固定底部导航（首页 / 场景 / NFC / 生活 / 设备），顶部设置和快速新增任务。
- 个人场景：学习、休息、开发、出门。仅操作网站内部状态。
- NFC：移除笔记本品牌特殊记录识别；新增本地标签注册、编辑、删除、绑定场景、Web NFC 条件支持时写入/读取站点 URL。
- 生活：个人提醒与物品清单；没有室友共享功能。
- 数据：兼容 V1 本地备份，额外保存 `nfcTags`, `reminders`, `items`，保持原状态版本号供旧数据迁移。
- 测试：语法 / 静态结构 / 浏览器桌面与手机尺寸操作测试。

## 已知限制

- 标签映射只存在当前浏览器；重新绑定后，已有写入的 URL 标签在其他设备可能仍指向原场景，需要重写或者后续增加同步服务。
- 写入标签的 URL 会被系统/读取者看到，不适合存储凭据，也不能作为身份认证。
- NFC URL 唤起只会操作网页，不能保证系统自动打开或后台执行。
- 关闭网页后，生活提醒不能自动推送系统通知。
- Android Web NFC 真机尚未验证。
- 没有完成登录、多设备同步和设备自动化 API。
