# 第二课堂本人活动分页读取 · 0.8.4

复用已可读取积分的官方 WebView 会话，固定同源 POST /sys/stu/center/signupactivity/list，使用既有 page/pagesize 契约。最多 25 页、250 条，每页校验本人身份、总数一致性、重复 ID、时间与数字格式；任一页失败均不返回可保存的部分结果。

积分、活动及完整读取元数据在同一 Room 事务中替换；零活动必须由已通过本人积分身份校验的会话返回 totalPage=0,totalSize=0,data=[] 才能清除旧活动。保存失败、取消、页面变化或登录失效保留旧数据。首次/不同账号仍需本人确认，既有设备加盐摘要用于同账号前台自动保存。

独立第二课堂页展示本人报名活动、开始时间、报名状态、结算状态、学校审核/验证状态码和读取时间。现有契约未证实审核码的审批语义，明确标注原始码而不推断审核通过；学校未提供的时间标为未知。仅已结算活动展示其已结算分数，不能与官方积分合计再次相加。

前台打开页面触发刷新，不是后台轮询或云端连接器。活动接口复用主分支已有契约；本人手机活动数量、时间、状态与官网逐条对照、跨页及零活动行为仍须真机验收，合成测试和 APK 不替代这些结果。
