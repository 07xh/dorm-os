# DORM OS V3.6 · 首页个性化工作台

本次仅更新个人网站。首页模块新增本地布局设置：支持显示/隐藏、上移/下移、恢复默认。模块包括今日课表、我的待办、专注计时、个人生活、我的设备和天气。

布局保存在当前浏览器的 DORM OS V1 settings.homeLayout 字段中。旧版 V1 数据和备份不含该字段时自动采用默认布局；备份导入时进行白名单过滤、去重并补齐新模块，至少保留一个可见模块。合并备份保留本机布局偏好，覆盖恢复则使用备份中的布局或默认值。

专注计时复用现有持久化计时器，不引入新的后台常驻任务。天气仍使用现有校区天气缓存和手动刷新逻辑。移动端改为单列，桌面端双列；不添加云同步或寝室共享。

验收覆盖模块显隐、排序、保存、刷新恢复、恢复默认、至少一个可见模块，以及设置页入口。
