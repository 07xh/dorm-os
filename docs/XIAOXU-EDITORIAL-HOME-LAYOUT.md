# 校序 · 编辑式信息布局（Gemini HTML 视觉参考）

基于用户提供的《07xh/LocalOCR 仓库全面技术审查与演进蓝图.html》和对应纵向截图。来源为**技术报告的视觉设计**，不是校序业务实现或可直接移植的完整 UI。

## 参考中的有效模式

1. **Answer-first**：先呈现日期、核心数值和真实状态，再放详细列表；降低装饰性提示的首屏占比。
2. **开放式信息条**：水平细分割线 + 大数字 + 较小标签，而不是每个统计值各占一张高圆角卡。
3. **Editorial rhythm**：章节由细线、标题、间距界定；相邻正文利用密度差异，而不是色块叠加。
4. **数据可视化与文字一致**：图形与旁边数字共享颜色语义，空数据不要绘制演示数据。
5. **窄屏优先**：长篇报告的 12 栏排版不能直接迁移到 360–400dp 手机；移动端保持单滚动容器、可触摸行和适度字号。
6. **避免字体依赖**：报告使用 Google Fonts；App 继续使用已有 Compose 字级和设备本地字体，不新增在线字体请求。

## 验收项目

- Android Kotlin 编译和已有布局/来源静态检查；CI 成功不代表真机截图完成。
- 320 / 360 / 393 / 600 / 840dp：日期不截断、统计标签清楚、7 天图表无溢出、快捷服务入口有足够点击区。
- 有课与无课、未连接与历史快照、无任务与多任务、无真实截止日期等真实状态均需正常展示；不得填充假数据。

- 回到原 HTML CSS 核对：表格无外框、无斑马纹；标题上边是浅灰细线，行项目以 `border-bottom` 分隔；高权重统计数字在开放背景上呈现，危险/提醒才用暖色。
- 本次将首页「优先处理」「校园动态」「学习通 · 本机作业」的嵌套 `XiaoxuCard` 改为**开放式 Column + 半像素分割线**；每行的真实标题、时间、任务来源及跳转仍取自原数据。
- 官方公告行仍至少 64dp 可点，优先处理继续由 `HomeTaskRow` 提供详情入口，学习通快照仍只可从既有入口重新读取，不为静态快照添加虚假操作。
- 任务页已存在的 `TaskSectionHeader` 在标题上增加浅分割线；保留 `TaskGroupHeader` 的可折叠玻璃表面，因为它承担实际展开/收起行为，不机械追求“全 0 圆角”。
- 既有源码静态测试定位由依赖中文注释改为依赖函数边界，新增结构回归检查，验证三个开放式列表、日期信息和原业务入口仍存在。

## 与原 HTML 设计语义的对应

| HTML 视觉规则 | 校序 Android 适配 |
| --- | --- |
| `--paper #F4F6F8` 和简洁表面 | 继续复用当前 `XiaoxuPalette` 的背景、正文和玻璃控制面，不开第二套配色 |
| `.hero-metrics` 顶部深色细线 + 大数字 | 首页待完成/近期截止开放式数值栏，绑定真实数据 |
| `.strip-item` 与 `tbody td` 细分隔线 | 课程后续列表、待办/公告/作业条目和任务分区以细线区分 |
| `.grid` 12 栏 + `col-left-4/col-right-8` | Compose 平板双列，手机单滚动列，不移植网页的硬 12 列 |
| `0px radius` | 仅内容区扁平化；底部导航、弹层、可折叠操作控件保留原交互圆角 |
| 使用 Google Fonts | 继续使用 Android 本机字体和 MaterialTypography，不联网加载网页字体 |
