# 校序：华水青果 HTML 课表解析器（第一阶段）

## 结构依据与隐私边界

只从本人 HAR 本地**提取页面结构**，不上交原始 HAR 或真实 HTML 内容：
- `/hsjw/student/wsxk.xskcb10319.jsp` 是 200 HTML 页面。
- 页面至少有一张周课表网格和一张带八列标题的课程明细表，两张可能共用 `id="mytable"`。
- 课程明细列名依次是：上课班级代码、课程、总学时、学分、修读性质、任课教师、选课状态、上课时间地点。
- 隐藏的 `xn` 和 `xq_m` 可用于核对学年、学期；**不要读取、缓存或复制学号 `xh`**。
- 上课时间地点中存在多段 `；` 分隔；部分片段没有完整周次、节次或教室。因此不能通过字符串拼接猜测不确定信息。

**这份 HAR 包含账号认证材料。不得提交 HAR、真实页面 HTML、用户名、密码、Cookie、Token、真实课表或个人身份信息到仓库、Issue、CI 日志。**

## 实现

`lib/academic-ncwu-html-parser.mjs` 使用项目既有 `cheerio`，不新装解析依赖、不新增网站页面：
- 根据八列标题识别唯一明细表，不依赖重复的 `#mytable` ID。
- 从指定学期与 `xn/xq_m` 交叉验证上下文；检测年份与学期不匹配直接失败。
- 解析支持的范围周次、奇偶周、星期、节次、地点。
- 无法解释或缺失的信息仅输出不带隐私值的 `{row,code}` 阻断项。
- 将可解析的课块送入现有拾光兼容归一化器 `candidateSchedule`，所有结果强制 `verified:false`、`complete:false`、`trustedSyncAllowed:false`。
- 解析器没有网络请求、学号读取、会话、密码、D1 写入或登录功能。

## 合成数据验收

`node scripts/xiaoxu-ncwu-html-parser-tests.mjs`

涵盖同 ID 双表、完整周次、单双周、分段、异常周次与节次、缺失课表、缺少地点、学期标识冲突、重复课块、登录页和超大响应拒绝；所有测试数据均是虚构课程。

## 后续阶段，不属于本 PR 完成内容

1. **真实授权会话**：确认学校允许且实际支持的登录流程、验证码交互、本人账号与学籍主体绑定；由现有 `academic-school-login` 服务端门禁接管。不得用 HAR 中的密码/Cookie 来拼接或试探认证，更不可在验证前开放站内密码输入框。
2. **独立逐项比对**：受控环境比对所选学期、总课数、逐日节次、起止周、单双周、老师、教室、调课与补课。对于不完整行只标注待核验，不修改真实数据。
3. **正式可信同步**：必须经过上述身份绑定、完整性、学年周次与课程 ID 验收；只用已验证适配器构造可信记录。HTML 解析器返回的候选数据本身不允许直接写入 `academic_verified_records`。
4. 成绩和考试分别获取**脱敏后的响应结构**与最小字段样本，不采集登录、密码或会话令牌。

## 实测 HTML 的保守结论

当前已有真实课表页面提供足够的八列结构参考，但“上课时间地点”存在无法无歧义解析的片段，故**尚不能宣布整张真实课表解析通过，更不能宣布学校账号连接成功**。
