# 校序 · 第二课堂连接方式（M22 无损精简）

截至 2026-11-03，第二课堂官网 `https://dekt.ncwu.edu.cn/` 使用学校
CAS 登录链，回调由校方 `sec.ncwu.edu.cn` 持有。
**这不需要学校额外提供第三方开放 API 才能研究本人只读连接器**，
但目前仍没有经过本人真实登录和会话持久化验证的校序站内连接实现。

## 唯一保留的正式方向

- 复用 `我的 → 数据连接`，不得额外建立登录页或第二套学业账户。
- 复用 `lib/academic-school-login.mjs` 服务端会话密文存储、
  `lib/academic-ncwu-second-class.mjs` 本人只读业务解析和
  `lib/academic-ncwu-second-class-sync.mjs` D1 原子写入。
- 通过学校允许的本人常规登录流程完成验证；登录态若无法在服务端正常建立，
  明确显示 `未连接`，不能声称已实现云端自动同步。
- 不绕过验证码、访问控制或保护机制；不向前端永久暴露学校密码或 Cookie。
- 学习通、青果不受本轮代码清理影响。

## M20/M21 废弃功能与历史数据

过去的 ScriptCat 安装、浏览器配对密钥、活动上传端点和相关前端按钮
已从当前代码移除，不再要求用户下载脚本或手动导入二课 JSON。

生产 D1 已运行过的 **0013/0014** 迁移属于不可篡改的历史版本，
源文件仍保留以便追溯；本轮不再执行其初始化，也**不删除生产表和历史活动快照**。
旧版写入的个人合计如果存在，继续仅作为历史个人快照显示，
不能冒充 `trusted_readonly` 来源。

历史提交中保留相关开发证据，但它们不是现行部署方式。
