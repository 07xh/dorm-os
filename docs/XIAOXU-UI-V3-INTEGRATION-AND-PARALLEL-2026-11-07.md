## 1. 不允许偏离的视觉/交互基线

1. 以用户提供的**北化课表 1.0.8.3 APK 与此前确认截图**作为视觉参考。复刻的是页面组件、排版、交互、弹层，不照搬北化的业务栏目或重新设计外观。源仓库新版本与 APK 不能默认视作同版。
2. **唯一设计 token/组件所有者**：`ui/XiaoxuDesignSystem.kt`。页面不得新增独立品牌色、第二套 GlassCard、悬浮导航或设置宿主；必要的统一控件先加兼容 API，再迁移调用。
3. **课表特例冻结**：顶部星期选择栏、现有课程颜色不改；周视图/日视图仅放在课表设置；课程详情仍从原屏幕底部弹出，不改位置、标题文字及信息组织；课程来自真实本机已保存数据。
4. **底栏冻结**：维持现有五入口及位置，尽可能贴近参考的液态玻璃透明度、折射、光照、图标、尺寸、按压/拖动、选中态；只允许改善手感、流畅度、稳定性、兼容性。尚未经同版源码及截图对照前不得标称像素级 1:1。
5. **页面风格统一**：紧凑顶部、适当放大的正文/消息点击区、统一圆角与卡片高度、低干扰文字色、无大面积解释性提示；任务/作业优先点击进入详情，不将页面做成连续下拉折叠卡或嵌入式网页。
6. **数据来源不变**：学校本人授权、`CloudClient`、Room、本机课程、微信审核任务、二课快照均保持现有契约；未连接/过期/失败/核验为空严格区分，不允许演示占位冒充真实记录。
7. GPLv3/其它上游代码必须确认许可兼容后才可直接移植；“不商用”不是自动豁免。依赖/工具链/原版素材的额外改动单列说明。
