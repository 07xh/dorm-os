# 第二课堂手机本机积分连接 · 0.8.2

本次用户明确恢复第二课堂开发，并授权 App 界面、构建与发布。复用原 NativeSchoolConnectActivity、学校 WebView 会话和 Room native_school_records，不新增云端连接器或替代学校登录页。

## 使用
我的 → 三个平台·本机读取 → 连接第二课堂／刷新积分。首次在学校官方页完成登录；会话有效时直接进入成绩单。点击读取／刷新本人积分，确认官网当前账号与汇总后保存，再返回校序。积分及六类明细保存在手机，可离线查看；时间为上次采集时间。登录态期限由学校决定，过期后重新登录。

## 读取边界
- 只在 https://dekt.ncwu.edu.cn/sys/stu/score 调用同源 POST /sys/stu/score/list，不导出 Cookie，不从其他浏览器或 App 搬运会话。
- 支持真实返回的 text/plain JSON、totalPage=0、六类积分以及 school_term_index=100 学校汇总；汇总不与学期重复相加。
- 已识别的学期行必须与官网可见账号一致；合计行可无学号，但匿名合计不能单独证明身份，混合账号拒绝。
- HTML、空数据、缺失身份、分页不完整、重复学期、非法数值、HTTP 错误、超时和页面跳转均不写入。取消保存保留旧记录。
- 只有固定脚本的脱敏投影进入原生；无 JavascriptInterface、无原生 HTTP Cookie 交接、无学校密码采集、无云端同步和后台轮询。

## 验收状态
Node 契约测试使用合成账号和合成数值；此前电脑官网页面对照不能冒充手机实测，个人实际数值不进入仓库。PR CI、主分支构建、可安装 APK 与本人 Android 16 验收各自独立。

手机验收：首次官方登录 → 身份与积分对照 → 确认保存 → 返回原页查看 → 关闭重进刷新 → 学校会话过期重登 → 断网不清空旧积分 → 取消不覆盖 → 学习通和课表不回归。发布版本仍保留该未验收列表，不能写「完全接入」。
