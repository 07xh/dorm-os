# 第二课堂独立页面与前台更新 · 0.8.3

用户已反馈前版可以读取。本次复用原官方会话读数路径，新增 SecondClassHomeActivity，从现有第二课堂入口进入；展示本机学校合计、学期、六类分项和读取时间，不要求云端登录。旧活动采集入口保留，但独立积分页不混入未绑定账号的历史活动。

已连接时每次打开此独立页面会尝试一次前台刷新；也可手动刷新。旋转屏幕和返回结果不自动再次发起。官方会话有效时读取后返回本页；过期需本人正常官方登录。首次保存或更换账号必须确认。

为防自动更新跨账号覆盖，本机随机盐保存在私有设置，只在官方页面内计算学号加盐 SHA-256；原生只收到摘要。只有摘要与前次确认一致才允许自动保存；不保存原始学号，不读取 Cookie、密码或票据，不对外发送摘要。失败保留旧快照，摘要不是学校授权会话。

范围为前台打开页面时更新，不是后台定时、Cloudflare 同步或原生 HTTP 会话交接。用户此前确认前版可读，不替代本版本独立页面、自动返回、账号变化与失效流程的真机验收。
