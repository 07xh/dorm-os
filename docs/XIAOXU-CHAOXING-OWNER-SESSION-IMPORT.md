# 校序｜学习通官方登录会话导入（第一阶段）

## 范围
仅适用于用户自己拥有并已经在**华水学习通官方网页**正常登录的会话。

这是原有「我的 → 数据连接」中的一个**备用连接方式**，不是独立账号系统，也**不是**官方 SSO 回调：
- 普通校序网页无法跨站读取学习通的 Cookie；打开官方网页登录后不会自动绑定。
- 用户明确选择导入本人的官方浏览器 Cookie JSON 数组，必须保留 `name`、`value`、`domain`、`path` 和原有域名作用范围。它相当于登录凭据。
- **不要把真实 Cookie、密码或令牌发到聊天、Issue、日志、公开文档中。** 只应在本人控制的校序 HTTPS 站点操作。
- 服务端只接受超星白名单域名，不允许浏览器控制接口地址，不放宽 host-only Cookie。无法通过验证则不存储。
- 服务端先向官方个人主页核验华水本人账号，再由原有收件箱适配器真正读取数据，才会将会话 AES-GCM 加密写入既有 `academic_provider_sessions`。
- 成功后使用原有 `/api/v1/connections/chaoxing/sync`、本人记录表和前台自动恢复逻辑；不新增数据库表或重复认证系统。
- 用户可以随时通过「解除连接」撤销。Cookie 到期时需要重新连接。

## Cookie 格式
仅支持浏览器导出的 Cookie **JSON 对象数组**，而非任意请求头、Cookie 文本、HAR、账户密码或跨站脚本。例如字段结构：

```json
[
  {
    "name": "cookie_name_placeholder",
    "value": "value_placeholder",
    "domain": ".chaoxing.com",
    "path": "/",
    "hostOnly": false
  }
]
```

上面均为占位符，不是有效登录 Cookie。**不得擅自将仅属于子域的 Cookie 改写为 .chaoxing.com**；必须保留真实来源域名和 host-only 标记。

## 验收门禁
- 静态和合成测试：Cookie 域名作用范围、错误格式拒绝、超星本人身份核验、真实数据读取门禁、AES-GCM 保存、会话刷新、页面重开恢复。
- **生产真人验收尚需本人完成**：官方登录后安全导入、课程/作业/收件箱逐项比对，重新进入后刷新。
- 本阶段**没有**打通华水青果或第二课堂的官方会话导入，也没有实现「官方网页登录即可无感把 Cookie 转给校序」。不得标为这三平台全部接通。
