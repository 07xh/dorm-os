# 华水青果课表：合成读取与逐项比对验收（M24）

## 目标与实现

沿用现有 `lib/academic-ncwu-page-reader.mjs`、`lib/academic-ncwu-html-parser.mjs`、`lib/academic-ncwu-timetable-compare.mjs` 和单一数据连接入口，不新建登录系统。

- 新增 `lib/academic-ncwu-schedule-audit.mjs`：服务端**只读证据审计函数**。使用外部已取得的本人有效学校会话，从固定的 `jwmis.ncwu.edu.cn` 路径读取课程 HTML；与**独立记录的官网课表参考值**按课程名、教师、地点、星期、节次、周次逐块比对。
- 返回仅含覆盖率、匹配/差异数量、阻断原因代码的汇总；不返回账号、Cookie、完整课表、课程名、教师、教室、带查询参数的地址。
- 新增 `scripts/xiaoxu-ncwu-schedule-audit-tests.mjs`，接入 `npm run check`。覆盖双表同名、全部合成课程逐块一致、教室变更、缺失时间片段、会话跳转、非法 Cookie。
- **即使完全匹配也只得到 `structure_matched_not_authenticated`**。这份独立审计不验证官方登录主体，不写入 D1，也不解除现有 `trusted_readonly` 门禁。

## 与实际账号连接的边界

校序「我的 → 数据连接」继续使用既有 `academic-school-login.mjs` / AES-GCM `academic_provider_sessions`。课表同步现已允许可信服务端仅处理 `schedule`，但缺少经验证的华水青果登录适配器及本人身份映射，不能声称网站已经可以连接学校账号。

真实联调需要在服务端验证：本人会话有效、身份绑定可证、真实页面完整、课程官方稳定 ID 与各字段无误。仅使用 HTML 解析到的候选记录必须保持 `verified:false`、`trustedSyncAllowed:false`，不能直接进入学业快照。官网参考数据必须**独立**核对；不要直接复制候选数组当参考，否则比对只能自证一致。
