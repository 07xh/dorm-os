# 校序 V9 · UI 精修预览

## 使用的设计方法
- Taste Skill app-screen：把颜色用在需要决策的数据与行动上，减少冗余彩色图标瓷砖。
- Impeccable adapt / animate / craft-floor：触控、移动端导航、信息层级、轻量过渡与减少动态效果支持。

## 本次修改
- 五个原有 data-page 页面按钮在手机端成为固定底部导航；没有复制路由或新增页面。
- 沿用主分支已上线的「我的 → 登录校序」唯一入口，不再创建顶部云端入口。
- 将首页计数卡改为更安静的数据层级；去掉装饰圈、旋转卡片及重复的“查看任务”快捷按钮，保留业务功能入口。
- 导航切换时约 220ms 轻过渡，不针对数据刷新反复动画；降低动态效果设置直接禁用空间动效。
- 兼容小屏/桌面/深色主题，保持 44px 左右的控件触控区与安全区底部留白。

## 业务边界
- 未改动任何课表、任务、通知、连接器、Cloudflare、个人登录、存储、NFC 业务代码。
- 真实个人学业数据未连接时继续显示未连接，禁止引入假课程、假成绩或假作业。
- 仅 PR 预览，不自行发布生产环境。

## 验收
1. npm run check 与 npm run test:e2e 通过。
2. 320/393/768/1365px 无横向滚动或遮挡，五个导航项和云端入口可点。
3. 任务新增、课表日/周切换、通知筛选、设置、深浅主题不受影响。
4. 减少动画、输入焦点和浏览器返回动作保持正常；最后仍需实体 Android 触控验收。
