# 校序 V8.1 · 教务工作台与通用组件第二批

## 本批改动
- 确认版 UI 的教务五个二级页面改为一致的卡片、导航、状态信息与可访问性语义
- 二级导航按 WAI-ARIA tabs/tabpanel 组织，支持左右方向键、Home、End 和焦点管理
- 成绩、考试、第二课堂在未接入本人授权数据时呈现明确且可操作的空状态，绝不出现编造绩点、考场或学分
- 校园公开通知继续沿用现有源、缓存和请求接口；统一其筛选、列表和官方链接样式
- 将课表星期选择、任务筛选、日程卡片的外观与 V8 设计令牌对齐
- 采用原生、可离线的渐进组件模式，避免 CDN 依赖导致 PWA 离线界面缺失；已有数据和 URL 不迁移
- 服务工作者缓存版本增加，确保新样式在已安装 PWA 中可以更新

## 验收
- `npm run check`
- `npm run test:e2e`：包含新页签键盘导航/准确空状态/360–1280 px 防横向溢出回归
- 真实个人教务数据需要独立合法授权接入；这次只完成 UI，不声称正式已连接青果
- Android 真机触控、NFC 和后台功能仍需单独验证
