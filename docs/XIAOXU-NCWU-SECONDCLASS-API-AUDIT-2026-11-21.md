# 华水第二课堂只读接口审查与接入门禁（2026-11-21）

> 审查依据：本人授权页面的脱敏接口结构记录（2026-11-21）与当前 main 代码。仅审查本人的可见只读业务；此文不含姓名、学号、班级、Cookie、HAR 原始正文、积分实数、活动原名或会话密钥。不代表学校实时联通或生产部署已验收。

## 状态定义
- **已观察**：授权页面的正常请求收到预期格式，不等于校序完成全链路接入。
- **已适配**：仓库已有解析/白名单/存储代码，但仍须真实账户验收。
- **待验证**：关键方法、字段、参数或真实非空业务结构没有足够依据，必须失败关闭。

## P0：接入前必须核准

1. **方法冲突**：在本人正常使用官方页面时，仅记录真实 GET/POST、Content-Type、表单字段名、分页结构及是否为业务 JSON。不得提交请求 Cookie、学号或响应个人值。旧 POST 已有独立历史证据，不能因为新 GET 返回成功就整体替换。
2. **本人身份**：官方学期行必须与受信任会话身份一致；school_term_index=100 合计行可无 student_code，但绝不能替代学期行作身份依据。有身份字段时，即使是合计行也必须匹配。
3. **活动 ID**：新记录突出 activity_id/signup_id，旧解析要求 id。必须对正常返回的实际字段作脱敏键名对照，区分报名记录 ID 和活动 ID，避免覆盖/误去重。
4. **活动广场**：取得合法正常页面的成功非空列表、必要表单/分页、状态及排序字段后，才扩展现有严格投影；不把本人报名列表当作全校活动目录。
5. **登录态**：302/HTML 登录页不能作空列表；只允许本人官方授权且可受信任绑定的会话。当前样本 sid 已失效，不提交/复用。

## P1：真实数据含义与完整性

1. **score_plus / score_plus2**：旧官网页面证据标注 score_plus 为“志愿服务时长”，新摘要将两项描述为额外加分；这是语义冲突。保持现有有证据的模型，但须再对照官方字段标签，未证实前不得合并两个字段。
2. **score_value_last、first_flag、exemption_flag**：新文档给出解释，但没有完整的页面语义对照；目前不据此开发“上学期”“必修”判定。
3. **汇总与学期**：term_index=100 是“合计”，绝不与分学期数据重复相加；对 totalPage=0 的非分页积分容器单独校验。
4. **报名状态**：signup_state、verify_state、activity_state 彼此独立；缺字段显示未知，未核算活动不得计为已获得积分。
5. **分页**：验证 startIndex 0/1 基数、page/pagesize、totalPage 与 totalSize 的行为，非空第二页、字段缺失、登录过期、请求失败均须保留旧快照。
6. **会话可靠性**：目前只存在并发可能导致会话失效的观察。先串行、低频、受控刷新；具体阈值与自动续期不可凭单次样本认定。

## P2：之后按需扩展

- 个人星级、成绩单、社团、志愿记录、活动任务、收藏和审批历史只在本人权限内验证数据模型；无必要不接入。
- 报名、取消、评价、核验、密码更改、文件上传等修改型接口均不纳入校序只读同步。
- 学校返回内部 SQL 异常或疑似授权边界问题仅按最小证据私下报告维护方，不开展利用测试。

## 与仓库现有代码的衔接

- Android：复用 `NativeSchoolConnectActivity`、`SecondClassAutoReadDriver`、`ncwu_secondclass_local.js`、`SecondClassPage`、Room 本地数据。
- Cloud：复用 `makeNcwuSecondClassAdapter`、`runVerifiedNcwuSecondClassSync`、既有 Access/D1 私人 API 和加密 Vault；不得另建登录器、定时同步或独立活动写通路。
- 本批可确定的兼容修复：允许无 student_code 的合计行，但要求至少一条受信任的同一学生学期行，并拒绝合计行身份错配；增加合成回归测试。
- **未完成门禁**：本机真实帐号同源 GET/POST 验收、活动目录非空样本、真机逐字段对照、重启与失效恢复、CI、生产部署。仅源码提交不代表已接入成功。
