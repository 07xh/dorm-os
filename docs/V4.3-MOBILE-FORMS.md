# DORM OS V4.3 · 统一移动端表单与弹窗

这个 PR 只改网站 UI，不修改本地数据结构、NFC 写入、KernelSU、Android App 或校园网脚本。

## 修复的体验问题
- 原桌面型编辑弹窗在移动端拥挤、长表单需要滚动才能找到保存按钮。
- 统一任务、课表、NFC 标签、个人提醒、物品等采用的 formFrame。
- 小屏改为底部抽屉式模态窗，标题和保存/取消区固定，字段独立滚动；桌面为居中模态窗。
- 保留原生 dialog 焦点管理与 Esc，CSS 适配安全区域、动态 viewport、减弱动画偏好。
- 标签、提醒与物品表单补全对应的 label/for/id；不更改入库字段名。
- 滚动层和颜色统一使用已有主题变量，兼容浅色与深色模式。

## 不能夸大
- 自动浏览器测试不等于一加 Ace 6 的实体 NFC/键盘真机验收。
- 仅在部署和版本 SHA 校验成功后报告线上生效。
