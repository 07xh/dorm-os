# 青果全量只读接入：接口契约第一批（2026-11-25）

依据 2026-11-17 用户提供的《华北水利水电大学教务系统接口全清单》与现有 main。只保留脱敏接口契约，不提交学号、姓名、密码、Cookie、原始 HAR 或真实成绩。

| 模块 | 主分支实现 | 本批状态 |
|---|---|---|
| 登录/会话 | 服务端适配器、AES-GCM vault、本人校验 | 复用，不更改登录 |
| 课表 | 正式主读取器、AJAX 候选、首次确认 | 保持现有行为，后续统一 |
| 考试 | 存储契约存在，实际 reader 仅 schedule | 新增轮次解析、参数构造、空结果候选判定 |
| 成绩 | 存储契约存在，实际 reader 仅 schedule | 新增年级候选解析、查询参数及评教状态判定 |
| 排名/学期/已选课程 | 需逐项核对 | 后续扩展 |
| 学籍/个人档案 | 用户明确排除 | 不开发、不展示、不保存 |
| Android | 仍保留官方 WebView 本地导入 | 待服务端真实验收后迁移为统一接口 |
| 公告 | 现有独立采集基础 | 复用现有管道 |

已知契约：考试先取学校官方服务索引中的考试轮次项，再查询本学期场次；课表与考试的学期格式不同。成绩接口被未评教业务规则限制时，不伪造空成绩，不绕过学校要求。全部调用限定本人授权的只读数据。

本批候选 reader 仍不加入正式同步、不会写 D1、不会改变已连接状态；缺少非空成绩和考试表格的脱敏结构样本，禁止猜测列名或将合成数据当实测。后续接入须核对既有材料是否已包含非空响应，否则在正常使用时获取脱敏结构，避免重新采集整套登录接口。仅在校方正常认证和本人账号授权下执行。

验收：`node scripts/xiaoxu-ncwu-readonly-candidate-tests.mjs`（合成测试）；生产真实账号、非空响应、跨设备显示仍需独立验收。

## 第二批：本人会话独立业务检查

新增受本人会话保护的 `business-check` POST 与现有数据连接卡片入口。成绩和考试手动独立检查，不启动后台轮询，不改变课表同步和正式快照。仅返回固定候选状态；不返回原始 HTML、身份字段或凭据。复用现有 vault 与独立限流桶，不新增数据库迁移；仅在会话仍一致时保存旋转后的加密 Cookie，不延长有效期。学籍模块明确排除；原成绩请求所必需的入学年级只在服务端临时提取，不展示或保存个人档案。真实非空明细结构及正式同步仍待验收。

## 第三批：教务页面直接查询

成绩、考试各自页面复用同一业务接口；不再在数据连接页堆叠额外按钮。考试轮次名称与对应候选状态可直接展示（非正式考试明细），成绩限制提示保留。查询状态只在当前页面会话内保存，不进入本地持久化；退出、断开授权或重新确认账号时清理，忽略旧请求。课表自动刷新与业务检查在同一客户端互斥。无学籍功能，仍不把未验证的非空表格写入正式快照。

## 第四批：一次授权、日常直接查询

复用既有 owner 会话与青果加密会话，课表页提供手动同步入口，成绩和考试页打开后自动查询接口状态（每域30分钟冷却；手动刷新仍受服务端限流），只在可见前台运行。课表、成绩和考试请求互斥；遇明确授权失效停止自动业务查询并引导检查连接。已保存的历史正式记录不因候选检查而清除。此批不新增密码存储、不自动绕过验证码或评教、不采集学籍、不新增后台 Cron。成绩考试自动查询仍仅限候选状态，不代表正式明细同步成功。

## 第五批：用户确认的同步策略

覆盖第四批旧默认：课表默认关闭自动同步，设置 → 更多设置 → 基本设置新增课表自动同步开关（设备浏览器本地保存，只有明确开启时才每30分钟进行前台刷新）。手动同步仍复用授权会话，不受开关限制。成绩只允许主动点击刷新；渲染、计时器、页面恢复均不得自动请求成绩。考试沿用原有前台自动查询策略，未改变候选数据核验限制。无后台同步、无学籍模块。本批暂未改动 Android 原生设置。
