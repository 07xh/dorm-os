# V4.5 手机端滚动、菜单和反馈验收

本轮不增加业务页面或重复功能，只修正真实手机常见的遮挡与操作密度问题：

- 固定底部导航保留安全间距；Toast 提示上移，不再覆盖底栏。
- NFC 标签、课表行、生活清单的更多菜单在手机端向上展开，并置于底栏之上。
- 菜单项最小触控高度 44px。
- 移动端避免整页程序化平滑滚动导致的跳动；表单/搜索/首页布局内部滚动保持原生触控惯性。
- 自动化检查 360px 下的菜单边界、Toast 与底栏间距、触控尺寸和导航唯一性。

边界：Playwright 模拟浏览器视口，不等于在一加 Ace 6 上实测触摸采样、帧率、系统手势冲突或实体 NFC。
