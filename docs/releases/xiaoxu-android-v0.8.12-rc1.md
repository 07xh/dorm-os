# 校序 Android v0.8.12 RC1 · 统一架构最新测试版

**发布范围：** 由 #351 当前原生 UI 集成分支及 #392 任务中心修复构建。正式分支 main 暂不被本次 Android RC 覆盖。

## 本次更新
- 保留北化课表风格的统一 Compose 原生玻璃 UI 与 #351 最新导航交互；继续保持任务列表无布局位移动画，解决频繁展开和勾选的跳跃风险。
- 任务中心：本机待办、学习通课程任务、普通云端任务、微信任务独立分类，初次进入默认收起。
- 从任务详情直接编辑既有本机任务的标题、本人标注来源和截止日期；Room 持久化，学校提交状态不受影响。
- 删除旧版“列表中插入两套编辑器+滚动到固定索引”的状态和计算逻辑。新建/管理在统一玻璃浮层内完成，避免正文被推移；编辑已有任务时仅展示一层弹窗。
- 微信个人完成状态仅通过已确认的本人云端写入更新，写入失败立即反馈并撤回临时勾选。
- 保留 #351 已合流的学习通可信 ID 核对、已提交课程作业的本机清理与恢复、第二课堂真实授权读取、个人本机课表等功能。

## 版本与分发
- Android `versionCode 33`，`versionName 0.8.12-rc.1`。
- 发布页仅提供与本次源代码 SHA 一致的 APK 及 `SHA256SUMS.txt`，不以历史构建产物替代。
- `debug APK` 使用 Android 默认开发签名；不同 CI 构建可能签名不同，不能保证覆盖安装。**有未备份的本机课表、任务或授权记录时，不要直接卸载旧版。**
- 这仍是 RC 测试版。学校授权有效性、真机流畅度及一加 Ace 6 连续页面切换与任务提醒需要在真实设备核对。无真实来源时不创建模拟学校数据。

## 正确下载
请以本版 GitHub Release 附件为准；旧版本附件仅作为历史留存，不再作为最新测试基线。
