# 校序 Android 0.8.11-rc.1 · 原生 UI 整合测试版

## 更新内容
- 保留唯一原生 Compose 主导航，五个主标签只组合当前页面，避免重型页面多次绘制导致卡顿。
- 设置分为「学习与课程」「账户与数据」「其他」，将「关于校序」移至末尾并删除重复品牌入口。
- 设置页宽屏居中限宽、窄屏正常铺满；第二课堂活动卡去掉与筛选状态重复的说明。
- 删除淘汰的整页动效源文件与专用测试，保留被设置、课表、教务页面实际调用的即时二级路由。
- 清退已经完成的历史 APK QA 构建请求文本文件；Git 历史仍可追溯。
- 保留学习通真实课程作业、第二课堂本人授权读取、任务中心及本机课表功能，不引入模拟学校数据。

## 版本与已知限制
- versionCode 32，versionName 0.8.11-rc.1。
- **测试版**：在一加 Ace 6 验收连续切页、真实数据、授权回跳和滑动帧数据前，不作为正式稳定版合入 main。
- 公开的 APK 默认使用 Android debug 签名；签名不同的旧版无法直接覆盖安装。不要为了体验测试版而卸载仍有本地记录的版本。
- 学校活动及积分的自动读取依赖本人真实会话，未授权时应呈现未获取状态。
