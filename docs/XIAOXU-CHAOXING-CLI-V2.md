# 校序 · 学习通开源工具原始 JSON 本地导入（V2）

## 支持范围与来源
参考 MIT 开源项目 [DanMo661/xuexitong-cli](https://github.com/DanMo661/xuexitong-cli) 的公开 `xxt hw --json` 与 `xxt hw-ls <课程> --json` 输出契约；适配器为校序另行编写的纯 JavaScript 数据层。此功能**不需要也不收集任何登录 Cookie、账号密码或课程页面 HTML**，输入文件只在本浏览器本地解析。

### 1. 截止日期看板（含精确时间）
CLI 示例（在本人的已授权学习通环境中自行运行）：
```sh
xxt hw --json
```
识别原始数组：
```json
[
  {
    "course": "高等数学",
    "title": "实验报告",
    "status": "未提交",
    "deadline": "2026-11-20 23:59",
    "url": "https://mooc1.chaoxing.com/mooc2/work/task?workId=345&courseId=789&enc=example"
  }
]
```
此处都是**格式演示数据**，不对应真实学校账号；原始 `url` 可能含会话签名，**不要把文件上传到第三方或 GitHub 仓库**。

### 2. 单课程作业（可能没有截止日期）
```sh
xxt hw-ls "高等数学" --json
```
其结构包含 `course`、`progress`、`items[{index,title,status,url}]`。若原数据不包含确定的截止时间，校序不覆盖已经保存的截止日期。请注意同名课程/多教学班的歧义；必要时在原工具指定准确班级。

### 3. 安全和去重
- 仅接受 `https://chaoxing.com` 或其子域名中的详情 URL，拒绝伪装域名、HTTP 和任意账号口令嵌入式 URL。
- 必须有可识别的 `workId`，校序从 `workId` 与可用 `classId/courseId` 组成去重键。查询签名、URL、enc、Cookie 一律**不进入持久化任务**；签名变化不会生成重复任务。
- 没有稳定 ID、数据形状不符、重复 ID、无效日期/任务格式时，整份文件拒绝导入，不做半成品导入。
- CLI 日期格式 `YYYY-MM-DD HH:mm` 解析为中国标准时间 `+08:00`；只含月日、无法确认年份的旧格式**不猜年份**，提示截止时间未知并保留旧记录。
- 官方平台状态与个人 `done` 独立保存，已提交不等于已批阅；新数据未返回旧作业不代表作业被取消。
- 新版旧数据迁移继续兼容 `dorm-os-state-v1` 和加密备份，`dueAt` 只保存已验证的中国标准时间数据；不会修改 NFC 网址。
- `hw --json` 本身只包含平台判断为“待提交”的作业，且可能因请求错误、课程未开放或视图过滤缺项而不是完整列表；**绝不能用于自动清空本地全部作业或断定本人所有作业已经提交。**

## 用户操作
打开校序网站 → 「任务」→「导入学习通 / 任务 JSON」→ 选择上述原始输出的 JSON 文件 → 查看变化与未知截止时间提示 → 手动确认。本功能尚未实现自动抓取或实时推送；后续自动对接必须验证华水本人授权数据、接口、会话权限与平台访问节流。

## 验收
- `node scripts/xiaoxu-chaoxing-cli-tests.mjs`：契约、稳定 ID、DDL、重复、安全域名、状态隔离。
- `npm run check && npm run test:e2e`：原有 NFC、备份、任务及手机/桌面浏览器回归。
- 真机学习通账号数据尚待独立验证，不以演示链接证明实际平台已经接通。
