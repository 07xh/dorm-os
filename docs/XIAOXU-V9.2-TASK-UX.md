# 校序 V9.2：任务列表触控与焦点连续性

## 用户问题
任务筛选为「待完成」时，勾选一个任务后它立即消失；之前的整页重绘只尝试按原任务 ID 恢复焦点，导致键盘/辅助技术用户失去焦点。手机端勾选框和编辑/删除按钮也小于常见 44px 触控目标。

## 本次修复
- 不改变任务状态模型、数据源或标记业务，只把现有复选框包入一个最小 44px 的点击标签；复选框本身仍是原生 input。
- 原任务依然存在时恢复同一复选框焦点。任务因筛选消失时把焦点转到下一条任务（最后一条则转上一条）；已无可操作本地任务时转到当前筛选按钮，保持连续操作。
- 复选框的无障碍名称随完成/未完成切换；移动端编辑、删除按钮各 44px，窄屏将次级操作换行，避免挤压任务标题。
- 不增加重复页面、不改变任务本地保存、已连接来源、真正的平台提交状态、登录和 PWA 缓存。

## 回归
通过 GitHub Actions 中原有完整测试并新增 Playwright：
- 待完成列表逐条勾选和无任务时的焦点回退；
- 全部任务筛选勾选后焦点恢复；
- 320/393/768px 触控目标与无横向溢出；
- 任务数据与原有路由保持不变。
