# 第二课堂自动读取

依据本人“开发自动读取，不用进入读取流程”和 #290。复用本机学校会话、固定 ncwu_secondclass_local.js、现有身份绑定、解析器和 Room。不导出 Cookie、不使用云端密码登录。

启动/回前台自动尝试：上次有效保存至少10分钟、上次尝试至少1分钟，同进程单任务；进入手动授权即取消。首次仍须本人授权确认，自动结果必须匹配已确认设备散列，账号变化必须走原确认入口。默认前台自动读取可关闭。后台独立开关默认关闭，WorkManager约30分钟，联网/电量非低约束，系统可延迟。

一次性 WebView 在主线程提供原脚本必须的官方页面上下文，不打开 Activity；固定成绩单地址，登录跳转立即停止，不提交登录表单。读取、页面切换、取消和超时有界；结束销毁容器。前台任务随 MainActivity 停止取消，后台仅在主动启用后调度。

保存前复核设置、同批来源与已确认账号；旧任务不得覆盖较新快照。失败/过期/取消保留旧数据，状态仅固定枚举，不保存页面/异常原文。不自动报名，不同步到云端，不影响其他来源。

验证策略/绑定/陈旧写入的 JVM 回归、现有固定脚本 Node 测试、Android编译和独立审查。离屏读取及后台省电行为必须真机验收；编译不作真实读取证明。当前QA临时签名不能假定可覆盖升级，保留已能读取的安装和数据。

实现补充：确认账号散列与快照一起写入现有Room表的内部account_binding记录，并从产品记录列表隐藏；不新增表。旧版本无绑定记录时，只以已有确认标记授权一次新的身份核对读取，不给旧记录推定账号。手动和自动均以请求开始时间排序，事务内校验当前绑定和旧批次。手动页面从创建到销毁及待完成保存的取消结束期间保留互斥。前台读取只由MainActivity拥有，设置开关不在Compose作用域独立启动任务。
