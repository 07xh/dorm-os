# 第二课堂本机官方会话连接

用户已明确恢复第二课堂开发并要求开发、上线 App；界面、APK 构建和发布纳入范围。沿用现有原工程及 NativeSchoolConnectActivity，不增加云端连接器或登录器。

首次从 App 打开官方 HTTPS 页面，由本人完成学校认证。连接入口直接定位官网成绩单，会话有效时继续使用 WebView 自有会话，过期则正常重新登录；不承诺学校登录态期限。凭据不由校序读取或导出。

已知真实契约为同源 POST /sys/stu/score/list；响应可能为 text/plain 内含 JSON。身份以可见本人标题和学期行学号一致为门禁；学校合计行允许无学号，但不能单独证明身份，存在不同学号仍拒绝。校验分页、重复学期、有限非负数字与六类积分，不将合计与学期再次相加。

固定只读脚本运行于指定官方成绩单页面。异步响应只投影脱敏结构，通过现有 evaluateJavascript 回调轮询接回；不创建 JavascriptInterface，不取 Cookie，不用原生 HTTP 继承浏览器会话。前后页面、请求批次和 Activity 生命周期均校验，失败不写入。

结果经本人确认后以 credits 类型存入现有 Room 来源隔离表，展示学校合计、分学期、六类分项和采集时间。取消及错误保留旧快照。活动列表继续使用原有功能，首版不声称全量活动同步或无人值守刷新。

选择本机同源读取，是因为本人官网交互登录和 JSON 已有证据，现有云端 CAS 链路仍失败；不尝试将电脑会话搬运到 Android。发布可安装版本与本人 Android 真机登录、重启续读、过期重登、断网保留旧数据分开验收。
