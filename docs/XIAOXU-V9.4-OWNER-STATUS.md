# 校序 V9.4：登录校序后自动读取学校连接状态

- 仅在服务端已验证的校序本人会话、且进入「我的 → 数据连接」（settings）时调用原有 /api/v1/connections GET。
- 只读取三平台的连接状态，不收集学校账号密码、不进行学校登录、不拉取真实课表成绩或作业，也不会自动开启云任务跨设备同步。
- 如果本设备此前已经主动开启云端工作台，则继续使用 V9.3 的既有恢复流程，本改动不重复请求。
- 未登录新访客不读取任何私有端点；服务端拒绝认证时不触发，失败不假装已连接。
- 登出后清空状态；使用 epoch 防止迟到的旧响应将私人连接状态重新展示。
- 学校真实账号登录仍需可信后端适配器 + 正规认证与本人身份校验；不能仅凭站内 UI 或学校官网打开动作认为已绑定。

自动验证：首次未认证访问无私有请求；可信会话进入数据连接页面仅有一次状态 GET；无私有快照拉取；登出竞态不回填旧状态。
